# 晚年文书包 v3 具体条款版设计

## 目标

把上一版的“栏目和空白线”升级成能直接交付给用户使用的文书包：每一份都同时包含说明手册、事实清单、具体条款、签署/见证/交付记录和保存复核表。

## 设计原则

1. 先事实、后条款。身份证号、亲属关系、权属、金额、账户、健康信息和日期必须先在清单里核对，再进入协议正文。
2. 条款优先于空泛表述。每个关键问题都写成权利、义务、权限、限制、期限、报告、违约、撤销或证据条款；下划线只用于真实事实和必要的个性化选择。
3. 公开材料只作为结构参考。生前预嘱包采用北京生前预嘱推广协会公开《我的五个愿望》的五部分框架，但不冒充协会官方文本，不声称医疗机构必然执行。
4. 文书与执行配套。每份文书都配签署要件、自查、保存位置、复印件、电子版、更新和交接记录。
5. 参考同行材料的完整字段。健康包吸收健康说明书和生活照护意愿书；财产包吸收财产情况梳理和医疗备用金；借款包吸收借款协议和维权手册的完整证据链。

## 六份文书包

### 1. 生前预嘱与健康照护包

分为个人健康说明书、个人生活照护意愿书、《我的五个愿望》、见证人声明、修改/撤回/保存说明、家属沟通记录。五个愿望分别落到医疗服务、生命支持治疗、他人如何对待本人、家人朋友知悉事项、无法决定时由谁协助五个章节；生命状态至少区分生命末期、不可逆昏迷、持续植物状态，并为每种状态提供“使用/不使用/仅为舒缓症状而使用”的选择。

### 2. 意定监护模板及指导手册

分为晚年支持地图、候选监护人筛选、意定监护协议、受托人接受声明、监督人确认、报告/账目/费用、替补和终止。协议明确触发条件、医疗和照护权限、日常财产权限、重大财产权限、禁止事项及需共同确认事项。

### 3. 银行事务授权模板及手册

分为医疗备用金、账户信息、授权事项、额度、期限、双人确认、用途限制、回执和流水保存、使用记录、撤销通知、银行受理/拒绝记录。明确授权书不替代银行内部规则，不把密码和验证码写入文件。

### 4. 房产车辆财产赠与协议模板手册

分为财产梳理、房产赠与、车辆赠与、其他财产赠与、附义务赠与、居住/使用、交付、登记、费用、风险、违约、返还/撤回、验收和过户记录。房产和车辆分别写特定权属字段和登记步骤。

### 5. 借条与还款确认模板手册

完整覆盖借款合意、用途、金额、交付、期限、利息、还款、抵充、逾期、提前到期、费用、担保、送达、管辖、生效和份数；另附借条、现金收据、分期表、还款确认、欠款确认、催款话术、录音提纲、电子证据固定和证据目录。

### 6. 再婚与婚前财产包

分为婚前财产清单、同居生活协议、居住安排、再婚/婚前财产协议、婚内财产协议、子女和父母责任、债务和传承衔接。每一类协议均写清财产归属、收益、共同购置、费用、债务、第三人告知、修改和保存。

## 版式

沿用现有自书遗嘱和非公证继承手册：A4、上下 1 英寸、左右 1.25 英寸、正文约 10.5 磅、Heading 1/2/3 黑色层级、短段落、提示段、表格和签署区。正式条款与提示段分开，避免把操作建议误抄进签署正文。
